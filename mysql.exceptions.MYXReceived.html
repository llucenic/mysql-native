MYXReceived

mysql exceptions

The server sent back a MySQL error code and message. If the server is 4.1+, there should also be an ANSI/ODBC-standard SQLSTATE error code.

class MYXReceived : MYX {
ushort errorCode;
char[5] sqlState;
}
