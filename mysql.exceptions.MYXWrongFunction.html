MYXWrongFunction

mysql exceptions

Common base class of MYXResultRecieved and MYXNoResultRecieved.

Thrown when making the wrong choice between mysql.commands.exec versus mysql.commands.query.

The query functions (mysql.commands.query, mysql.commands.queryRow, etc.) are for SQL statements such as SELECT that return results (even if the result set has zero elements.)

The mysql.commands.exec functions are for SQL statements, such as INSERT, that never return result sets, but may return rowsAffected.

Using one of those functions, when the other should have been used instead, results in an exception derived from this.

class MYXWrongFunction : MYX {}
