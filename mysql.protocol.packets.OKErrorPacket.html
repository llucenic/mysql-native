OKErrorPacket

mysql protocol packets

A struct representing an OK or Error packet.

OK packets begin with a zero byte - Error packets with 0xff

struct OKErrorPacket {
bool error;
ulong affected;
ulong insertID;
ushort serverStatus;
ushort warnings;
char[5] sqlState;
string message;
}
